feat(pincode-service): add pincode lookup service with city & pincode search

### Overview
Integrated **Indian postal pincode database** (`pincode` table) into the application with full search capabilities:
- Search by **city/district/office name** (partial, case-insensitive)
- Search by **exact pincode**
- Support for **composite primary key** with `@EmbeddedId`

---

### Key Features
- **Composite PK**: `OfficeName`, `Pincode`, `District`, `DivisionName`
- **Fuzzy city search** via JPQL with `LIKE` and `LOWER()`
- **Exact pincode lookup** using Spring Data JPA method naming
- **Clean DTO** (`PincodeOfficeDto`) for API responses
- **REST endpoints**:
  - `GET /api/pincode/search?city={name}`
  - `GET /api/pincode/by-pincode/{pincode}`

---

### Technical Implementation
#### Entities
- `PincodePrimaryKey` (`@Embeddable`)
  - All 4 PK fields with explicit `@Column(name = "...")`
  - `int pincode`, `Integer delivery` (nullable)
- `Pincode` (`@Entity`)
  - `@EmbeddedId` with **no `@AttributeOverrides`** (resolved via naming strategy)
  - All non-PK fields with `@Column(name = "...")` to match PascalCase DB

#### Repository
- `PincodeRepository` extends `JpaRepository<Pincode, PincodePrimaryKey>`
